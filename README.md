# Patrones Lab

**Patrones Lab** es un laboratorio de análisis de datos enfocado en explorar el mundo real a partir de **información pública y cotidiana**.

El objetivo del proyecto es identificar **patrones, dinámicas y comportamientos** en sistemas reales —transporte, movilidad, servicios, actividad económica— utilizando análisis exploratorios y predictivos, con un enfoque claro en el contexto y la interpretación.


## ¿Qué vas a encontrar en este repositorio?

Este repositorio agrupa una serie de **análisis independientes**, organizados por proyecto.  
Cada proyecto corresponde a un estudio concreto y contiene:

- datos procesados y/o agregados  
- notebooks con el análisis reproducible  
- visualizaciones (gráficos, imágenes, HTML interactivos)  
- una breve documentación del caso  

La estructura general es la siguiente:

```
patrones-lab/
├── YYYY-MM_tema-del-analisis/
│   ├── data/
│   ├── notebooks/
│   ├── visuals/
│   └── README.md
```


## Enfoque del proyecto

- Datos del **mundo real**
- Fuentes **públicas y abiertas**
- Análisis **exploratorios y predictivos**
- Código **abierto y reproducible**
- Prioridad en **criterio analítico** antes que en herramientas

Este proyecto no busca mostrar frameworks ni stacks específicos, sino **cómo pensar con datos** y cómo extraer información útil de fenómenos cotidianos.


## Sobre los datos

Los datos originales provienen de **fuentes oficiales y públicas**.

Por razones de tamaño y naturaleza de los archivos, los **datos crudos completos no siempre se incluyen** en el repositorio.  
En su lugar, se publican versiones procesadas, agregadas o derivadas, junto con la documentación necesaria para reproducir el análisis a partir de la fuente original.

Cada proyecto documenta claramente:

- el origen de los datos  
- el período analizado  
- las transformaciones aplicadas  


## Estado del proyecto

*Patrones Lab* es un proyecto en desarrollo continuo.  
Se incorporan nuevos análisis de forma periódica, cada uno como un caso independiente.


## Contacto y contexto

Este repositorio forma parte del proyecto **Patrones Lab**, con contenidos visuales y explicativos publicados también en LinkedIn e Instagram.

El código y los análisis están disponibles con fines educativos y exploratorios.
